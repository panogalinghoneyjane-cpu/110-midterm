Our Project

What is QuietNook?

QuietNook is a single-page book search application. Users type a title, author, or subject, and the app fetches matching books from the Open Library API, showing covers, authors, publication years, and descriptions.

Main Goal

To make finding academic and leisure reading materials fast and easy, while practicing HTML, CSS, and JavaScript skills such as fetch(), async/await, JSON parsing, DOM manipulation, and error handling.

Key Features

  • Search by keyword, title, author, or subject.
  • Book details with description.
  • "My Reading List" saved in the browser.
  • Recent searches and pagination.
  • Friendly error messages.
